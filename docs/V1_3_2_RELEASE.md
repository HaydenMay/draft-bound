# Draftbound v1.3.2 — Stability and usability

**Release date:** October 24, 2026

This release protects collections at the supported 1,000-entry binder limit, freezes synthetic v1.3.1-format saves for future migration checks, defaults new prospects to Full creation while retaining Quick, improves mobile editing controls, and clarifies that a coach intervention applies to the next game only.

No existing ratings, random offer rules, training growth, simulation outcomes, draft/pro outcomes, induction rates, achievements, saved results, save schema, or rules version are intentionally changed. Existing local saves retain their saved creation mode and random state.

The WR game loop and 16 interface palettes remain intact. QB/RB/TE remain unavailable previews. v1.4 gameplay redesign and v1.5 card artwork remain deferred. For test evidence and any deployment-state limitation, see the [v1.3.2 validation report](validation/V1_3_2_REPORT.md).
