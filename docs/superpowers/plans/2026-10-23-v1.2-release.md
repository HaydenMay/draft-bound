# Draft Bound v1.2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task, with a fresh whole-change review at the end.

**Goal:** Implement the user's approved v1.2 gameplay, presentation, setup, branding and theme improvements without changing completed careers.

**Architecture:** Keep deterministic pure domain transitions, optional backward-compatible save fields, shared vector geometry and resolved color tokens. Build on the unpublished coaching/reveal/broadcast modules, validating them rather than rewriting them. Keep cosmetic randomness and animation clocks outside gameplay RNG.

**Tech Stack:** Angular 21, TypeScript, native CSS/SVG/Canvas, Vitest, Playwright. No new runtime library.

**Spec:** ../specs/2026-10-23-v1.2-planning.md

## Global Constraints

- Four-game college training blocks, one natural gift, size roll, attribute/ceiling distinction, uniform eligible player rolls.
- Unique source players within an offer; players can repeat between offers.
- Hall of Fame criteria and school coefficients/names remain unchanged. Optional NFL career remains an automatic sim.
- Completed saves/cards keep frozen identities, traits and results. New fields must default compatibly.
- Artwork/appearance work is deferred to v1.5. Only approved interface/brand SVGs are integrated.
- No additional playable position. Future position labels are informational Coming soon options.
- Keep color literals in src/colors.css, with college/team colors in data.
- Preserve the user's two exact AGENTS.md principles and existing work on feat/prospect-broadcast.

## Review Focus

- Reloading during Full creation or a saved broadcast must not reroll or lose assignments.
- Missing/invalid optional palette, mode and balance-version fields must default or reject without corrupting old saves.
- Old active runs must not silently change progression coefficients; completed records are never recalculated.
- Inline logo masks need unique IDs per instance and equivalent Canvas export; contextual accent colors must remain legible on filled buttons.
- Growth/cosmetic choices must not consume gameplay RNG; both creation modes need complete journey/save tests.

## Implementation defaults

- Quick: gift + size + three manual potential assignments + five automatic assignments.
- Full: same gift and size flow, then eight manual assignments from three-player offers. Three shared rerolls in either mode; choose once before creation. No direct unrestricted catalog selection.
- Original forest default; include the five proposed palettes with deliberate light/dark values. Appearance remains an independent setting. Save a palette ID, not raw colors.
- Random name prefill with editable text and explicit reroll action, using a cosmetic generator.
- Keep the 75/25 potential/initial recruitment score; calibrate fixed star bands against source coverage rather than dynamic cohort-relative stars.
- Tune elite growth using a new balance profile for new runs; old runs keep the existing profile. Preserve original 7.2 practice allocation and participation budgets. Document actual rates before/after and the implementation-selected target range rather than claiming user-approved numeric targets.
