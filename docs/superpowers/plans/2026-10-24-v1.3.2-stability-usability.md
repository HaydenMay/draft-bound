# Draftbound v1.3.2 Stability & Usability Implementation Plan

> **For agentic workers:** Implement this plan inline with `superpowers:executing-plans`; follow TDD for each behavior and keep the work within the approved v1.3.2 handoff.

**Goal:** Ship the approved v1.3.2 reliability and usability fixes while preserving v1.3.1 saves, gameplay outcomes, and GitHub Pages behavior.

**Architecture:** Keep gameplay rules and RNG unchanged. Centralize the supported binder-entry limit at the persistence boundary, protect game-store mutations at that boundary, and use UI-only defaults for new creation flows. Keep compatibility fixtures synthetic and deterministic.

**Tech Stack:** Angular 21, TypeScript, Vitest, Playwright, IndexedDB, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-24-v1.3.2-approved.md` (verbatim copy of the owner-approved attachment).

## Global Constraints

- Preserve all existing WR gameplay rules, RNG consumption, saved outcomes, and the v1.3.1 save schema.
- Existing active runs retain their saved `creationMode`; Full is the default only for fresh creation flows.
- `MAX_BINDER_ENTRIES` remains 1,000; reject oversize imports before replacement and never persist entry 1,001.
- WR remains the only playable position; QB/RB/TE remain equally sized, visibly locked tiles.
- Do not add new services, accounts, analytics, ads, contact delivery, artwork, or v1.4/v1.5 gameplay.
- Keep `/draft-bound/` Pages routing, independent card colors, and legal publication notices intact.
- Run the complete unit, browser, typecheck, and Pages build checks before completion.

## Review Focus

- 1,000 entries plus an active run reaching draft completion: preserve a valid exportable save, do not append or drop entries, and present an accurate no-card-added outcome.
- 1,001-entry import: reject before replacement with a clear count/limit explanation.
- Legacy active run without `creationMode`: do not mutate it during resume; opening a fresh creator selects Full.
- 320px viewport with native controls and modal open: no page overflow, clipped fields, or inaccessible position choices.
- Coach intervention both compliant and substituted: displayed copy must describe the first game only; training rules remain unchanged.
